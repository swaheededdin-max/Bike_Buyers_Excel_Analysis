Bike Buyers Data Analysis & Interactive Dashboard

Project Overview

This project focuses on analyzing customer demographics and purchasing behavior to identify patterns associated with bicycle purchases using Microsoft Excel.

Project Objectives

- Analyze customer demographics and purchasing behavior.
- Explore factors associated with bike purchases.
- Identify customer segments and trends.
- Present findings through an interactive Excel dashboard.

Dataset

The project uses the Bike Buyers dataset, containing customer information such as:

- Marital Status
- Gender
- Income
- Children
- Education
- Occupation
- Home Ownership
- Cars
- Commute Distance
- Region
- Age
- Purchased Bike

Tools & Skills

- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Interactive Dashboard Design
- Data Analysis & Visualization

Project Structure

- "Dataset/" – Original raw dataset.
- "Bike_Buyers_Analysis.xlsx" – Complete Excel project, including the raw data, working sheet, pivot tables, and dashboard.
- "Bike_Buyers_Dashboard.pdf" – PDF preview of the dashboard.

Dashboard

The interactive dashboard provides a visual overview of customer purchasing behavior and allows users to explore the data using interactive slicers.

Key Outcomes

The analysis explores customer characteristics and purchasing patterns to support better understanding of potential bike buyers.
